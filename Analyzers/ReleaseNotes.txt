v1.1.0

**BREAKING CHANGES:**
* GD-484: The analyzers are built against Roslyn 5.0 and need the .NET SDK 10.0.100 or Visual Studio 2026.
          An older compiler reports the warning CS8032 and does not run the analyzers.

✨ New Features
* GD-502: GdUnit0202: Test case names must be unique, reports TestCase attributes of a test method that set the same TestName,
          contributed by @Tayrtahn.

✨ Improvements
* GD-478: The DataPoint attribute analysis caches the resolved types per compilation and runs faster, contributed by @Tayrtahn.

🪲 Bug Fixes
* GD-462: Fixing a stack overflow that crashes the compiler when a test or test hook calls a recursive method,
          the Godot runtime check now stops on methods it is already analyzing.

v1.0.0
This is the Initial release of the analyzers.

GdUnit0201: Multiple TestCase attributes not allowed with DataPoint
GdUnit0500: Godot Runtime Required for Test Class
GdUnit0501: Godot Runtime Required for Test Method

Features:
- Compile-time validation of GdUnit4 attribute combinations
- Provides clear error messages with method name identification
- Integrates seamlessly with Visual Studio and other IDEs

Integration:
- Built for .NET Standard 2.0 compatibility

Technical Details:
- Implementation based on Roslyn analyzer framework
- IDE support for real-time error detection
- Includes a help link to documentation
